# Raspberry Pi Arduino Setup

Installation and environment configuration guides for Arduino development on Raspberry Pi.

## Setup Guides

- [Arduino IDE Installation](setup/arduino-installation.md)
- [Board Package Setup](setup/esp-board-setup.md)

## Scope

This repository documents software installation, board configuration, and library management.

ESP32-C3 projects, display tests, wiring guides, and experiment sketches are maintained separately in [ESP32-C3 SuperMini Lab](https://github.com/INFINITE242/esp32-c3-supermini-lab).

## Platform

- Raspberry Pi
- Debian Linux
- Arduino IDE
- Arduino CLI
